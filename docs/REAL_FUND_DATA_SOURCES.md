## Prototype interpretation rules

1. These are **real published numbers**, but they are not synchronised to one common market date. Each metric is labelled with its source date or reporting period in the prototype.
2. PPFAS publishes a base expense ratio (BER) in the selected factsheet. The UI labels it BER rather than presenting it as the full TER. HDFC and UTI values are labelled TER.
3. UTI return data is Regular Plan Growth, while NAV and expense are Direct Plan Growth. The UI displays that plan distinction explicitly.
4. No rolling-return observations or risk metrics are inferred from trailing returns. Missing values are labelled unavailable or omitted.
5. Holdings and portfolio exposures shown are selected disclosure lines, not complete holdings files.
6. Nothing in this prototype is a live feed. Refresh and reconcile the source data before using it in a production or public investment-facing experience.
